# Stickers and drawings

Add up to 40 layers. Select a sticker to move, resize, rotate or remove it using keyboard-accessible sliders. Select a drawing to remove it. Ink applies to new layers. Use Undo / Redo for the last 30 decoration edits; the history clears on page reload, while the finished layers remain in your recovered draft.

Draw on the outlined preview using mouse, pen or touch. Each stroke is one layer, capped at 400 points. Leaving drawing mode restores normal page scrolling on the preview. Pointer cancellation discards the unfinished stroke. Stickers provide an alternative to freehand gestures.

Coordinates are relative to the paper, so changing export resolution does not shift the artwork. Changing paper shape may change how the composition looks; check the preview. The canvas renderer clips artwork to the paper and includes it in JPEG, PNG, GIF and cloud copies. Everything remains local until you explicitly create a cloud link.
